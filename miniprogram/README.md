# 订了个啥 · 微信小程序版

与网页版同一套核心算法（`utils/core.js` 与仓库根目录 `core.js` 逐字相同，node 单测结果一致：示例账单 7 个订阅 / 累计 ¥1,665 / 疑似多扣 ¥335）。账单文件通过 `wx.chooseMessageFile` 在本机读取解析，**不发起任何网络请求**。

## v0.2.2 更新

- **准确率**：排除高频、间隔密、金额零碎的按单消费误报；每项给出“较确定 / 疑似订阅”和判断原因，用户可把误报项移出本次报告并即时重算。
- **订阅详情**：展开查看首次/最近扣费、历史间隔、周期估算的下次扣费日期、估算月均与年支出，并逐笔列出日期、说明、来源和金额。
- **关闭清单**：每项可标记“待确认 / 还在用 / 准备关闭 / 已关闭”，页面汇总准备关闭与已关闭项目按当前周期估算的年支出。状态只保存在当前页面内，不上传、不持久保存。

## 本地预览 v0.2.2

1. 不要覆盖正在审核的 v0.2.1 本地目录；把 v0.2.2 代码单独解压或拉取到一个新目录。
2. 打开微信开发者工具，选择「导入项目」，目录选新代码里的 `miniprogram/`，AppID 使用项目配置中已有的正式 AppID，后端服务选「不使用云服务」。
3. 先在模拟器核对示例报告仍为 7 个 / ¥1,665 / ¥335，再测试展开明细、切换关闭状态、移出误报并恢复。
4. 再用「预览」扫码到真机，选一份自己的 CSV 账单，核对逐笔明细和报告卡保存。
5. v0.2.1 审核未出结果前，只做本地预览，不要上传 v0.2.2 覆盖当前审核流程。

## 上线步骤（只有第 1 步必须账号本人操作）

1. **注册小程序**：打开 mp.weixin.qq.com → 立即注册 → 小程序 → 个人主体（免费，微信扫码 + 身份证实名）。名称建议「订了个啥」；类目选「工具」下的「记账」或「效率」（以注册时可选列表为准）。注册完在「设置 → 基本设置」里拿到 **AppID**。
2. **填 AppID**：把本目录 `project.config.json` 里的 `touristappid` 换成你的 AppID。
3. **导入预览**：下载安装「微信开发者工具」，导入本 `miniprogram/` 目录，真机预览测试：示例报告、选账单（先把 csv 发到文件传输助手）、保存报告卡。
4. **隐私指引**：mp 后台「设置 → 服务内容声明 → 用户隐私保护指引」按实填写：本小程序仅读取用户主动选择的文件用于本地计算，不收集、不上传任何信息。
5. **提交审核**：开发者工具点「上传」，再到 mp 后台「版本管理」提交审核。审核说明可写：工具类应用，用户选择本地账单文件后在设备本地解析统计，全程无网络请求，附网页版地址作为功能说明。
6. **发布**：审核通过后在后台点发布。

## 已知限制

- 支付宝账单是 GBK 编码：小程序运行时若不支持 TextDecoder("gbk")，支付宝文件可能读不出，页面会提示改用网页版；微信账单为 UTF-8，不受影响（本机手动解码）。
- 一次最多选 2 个账单文件（微信 + 支付宝各一，足够）。
- 报告卡保存到相册需要用户授权相册权限，拒绝后有提示。
