# 订阅漏钱体检 · sub-leak-check

> 视频会员开了两个？网盘续了三年没打开过？音乐 App 早卸载了还在扣？
> 把微信 / 支付宝账单拖进来，本地算出你的自动续费清单和「疑似漏钱」金额。

**在线使用（推荐）**：https://woodrelfay.github.io/sub-leak-check/
打开网页 → 拖入账单 CSV → 当场出报告，还能生成一张报告卡图片晒给朋友。

**隐私是这个工具的立身之本**：全部计算在你自己的浏览器里完成（纯前端、零后端、无统计、无第三方资源），账单不上传、不联网、作者看不到。代码全开源，不放心可以自己审查，或下载到本地离线打开 `index.html` 用。

**不信可以亲手验证**（页面里也写了）：① 打开页面后断网，再拖账单——能出报告就没经过服务器；② F12 打开网络面板，拖账单全程零新增请求；③ 用 Release 里的离线版 zip，断网在本机跑同一套代码。另外请记住：**本工具永远不会让你输入任何密码、验证码或账号**，索要这些的页面一定是假冒。

## 为什么做它

- 黑猫投诉上「自动续费」相关投诉累计 22 万+ 条，仅 2025 年就新增约 6.9 万条，其中约七成是诱导开通或扣款前无提醒（腾讯新闻 2026-03-15 报道）
- 海外调查里，消费者自估每月订阅支出 $86，实际平均 $219；42% 的人在为已停用的服务持续付费（C+R Research）
- 而国内的「官方解法」至今仍是：自己去微信/支付宝里一个个页面翻扣费服务

没人把你手里现成的账单文件，变成一份一眼看懂的漏钱报告——所以做了这个。

## 它能查出什么

把导出的账单（建议满 12 个月）拖进来，它会识别固定周期重复扣款（订阅），并标记三类问题：

| 标记 | 含义 |
|---|---|
| **同品类重复** | 同一品类两个会员同时在扣（如两个视频 VIP），保留最近单价最高的一个，其余的累计金额计入「疑似漏钱」 |
| **悄悄涨价** | 同一订阅单价中途变高，涨价后每笔多收的差价累加计入「疑似漏钱」 |
| **连续扣费 N 个月** | 扣了很久了，提醒你逐条确认还在不在用 |

结果页会给出每个订阅的关闭路径（微信自动续费 / 支付宝自动扣款 / 苹果订阅），并能生成一张 1080×1440 的报告卡图片。

核心识别会排除一类常见误报：同商户高频、间隔很密且金额零碎的按单消费（例如随外卖订单购买的神券包），不会仅因“每月多次出现”就当作订阅。

**口径声明（重要）**：「疑似漏钱」是按上表规则的**估算**，账单只能证明「在扣费」，证明不了「你没在用」。请逐条确认后再关，别把在用的也关了。本工具只做体检，不替你取消任何订阅。

## 账单怎么导出

- **微信**：关注「微信支付」公众号 →「我的账单」→「账单下载」→ 用途选「个人对账」→ 选时间段 → 邮箱收到带密码压缩包（密码在公众号消息里）→ 电脑解压出 `.csv`
- **支付宝**：电脑端官网「交易记录 → 下载账单」选 `.csv`；或 App 内账单页申请交易流水证明
- 支持多文件：微信 + 支付宝各一份可以一起拖进来合并体检

## 本地运行 / 开发

```bash
# 方式一：直接双击打开 index.html（file:// 也能用）
# 方式二：起个静态服务器
python3 -m http.server 8000   # 然后打开 http://localhost:8000
```

零构建、零依赖。结构：

- `index.html` 页面与样式
- `core.js` 核心逻辑：CSV 解析（微信/支付宝表头自动识别、UTF-8/GBK 双编码）、商户词典、续费识别、漏钱口径 —— 无 DOM 依赖，可单独引用
- `app.js` 页面交互与报告卡 Canvas 绘制
- `demo-data.js` 示例账单（虚构人物「小林」的 12 个月账单节选，与 `samples/` 同源）
- `samples/` 两种格式的示例账单文件，可直接拖进页面测试
- `tests/core.test.js` 核心逻辑单测（`node tests/core.test.js`，断言数字均为手工核算）

商户词典在 `core.js` 的 `MERCHANTS` 里，欢迎 PR 补充（关键词 → 标准名/品类）。
