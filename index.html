「不上传」不能靠我嘴上说，给你三招自证，任选其一：

  1. 断网测：先打开本页，然后关掉 Wi-Fi / 开飞行模式，再拖入你的账单。能正常出报告，就证明计算没经过任何服务器
  2. 看网络面板：电脑浏览器按 F12 打开「网络（Network）」面板，再拖入账单——全程不会新增任何请求，本页连统计和字体都是本地的
  3. 用离线版：到 GitHub 仓库的 Releases 下载离线版 zip，解压后断网双击 index.html 使用，和在线版是同一套代码

账单怎么导出？（微信 / 支付宝各 1 分钟）
  1. 微信：关注「微信支付」公众号 → 底部菜单「我的账单」→「账单下载」→ 用途选「个人对账」→ 选时间段 → 邮箱收到带密码的压缩包，密码在公众号消息里 → 在你自己电脑上解压出 .csv
  2. 支付宝：电脑打开支付宝官网登录 →「交易记录」→「下载账单」选 .csv 格式；或 App 内「账单」页申请交易流水证明
  3. 时间段建议选满 12 个月，扣得越久越看得出规律
常见问题：数据存哪？为什么免费？准不准？
我的账单数据存到哪了？只存在你浏览器当前页面的内存里，关掉页面就消失。本站没有服务器，没有数据库，没有账号系统，想存也无处存。
为什么免费？作者自己被自动续费坑过，做了自用，顺手开源。代码托管在 GitHub，零运营成本，不需要靠你的数据挣钱。
「疑似多扣」准不准？它是按固定规则的估算：同品类重复订阅 + 涨价多收的差价。账单只能证明「在扣费」，证明不了「你没在用」，所以请逐条确认后再关。
苹果订阅的账单在哪？苹果订阅多经微信/支付宝扣款，一般已包含在账单里；明细可在 iPhone「设置 → 订阅」里核对。

关于作者

「会做梦的服务器」——一个做运营的，日常被各种自动续费教育，干脆写了这个工具自查自纠。工具开源在 GitHub（仓库名 sub-leak-check），有识别不出的订阅、或者对结果有疑问，欢迎到仓库提 Issue，词典会持续补。
仓库地址：github.com/woodrelfay/sub-leak-check

口径说明：「疑似多扣」= 同一品类的重复订阅（保留最近单价最高的一个，其余计入）+ 涨价后每笔多收的差价累加，是估算值，不是定性结论，最终以你逐条确认为准。识别基于账单内固定周期重复扣款，个别一次性消费可能被误判，请以标记为参考。
